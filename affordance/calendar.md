# calendar
> skill: lark-calendar

## +subscribe

### Avoid when
- Joining a single event from a share token → use [[+join-event]].
- Listening for calendar change notifications → use the lark-event workflow.

### Prerequisites
- Locate the target calendar with [[calendars search]] or [[calendars list]].

## +unsubscribe

### Avoid when
- Deleting a calendar and its contents → use [[calendars delete]].

### Prerequisites
- Select an existing subscription using the same identity that subscribed.
