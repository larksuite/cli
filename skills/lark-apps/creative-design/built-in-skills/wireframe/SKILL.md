# 线框图

帮助用户快速探索设计想法。先访谈用户，再生成多个粗略的线框图，在锁定方向之前把设计空间勾勒出来。优先追求广度而非精细打磨：每个想法给出 3-5 种明显不同的方案。用简单的形状、占位文字和极少的颜色，把焦点留在结构和流程上。整体保持手绘草图的感觉——手写风格但清晰可读的字体；以黑白为主、点缀少量颜色；低保真、简洁。提供简单的微调控件（Tweaks）；选项占地小就并排展示，占地大就用 tab 控件切换。
